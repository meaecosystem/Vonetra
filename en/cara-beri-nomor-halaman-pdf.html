How to Add Page Numbers to a PDF for Theses and Papers

Theses and papers usually need different page-numbering formats throughout: Roman numerals for the preface, regular numbers for the body, no number at all on the cover. Here's how to set that up within a single PDF.

October 1, 2026 · 2 min read

PDF Page Numbers supports more than one numbering format within a single document — you can create several "sections" with different numbering rules, such as no number on the cover, Roman numerals for the preface (i, ii, iii), then regular numbers starting from 1 for the body. This is the standard format usually required for theses and academic papers.

Steps to add page numbers

  1. Open tools.meaecosystem.com/page-numbers.
  2. Upload the PDF file you want to number.
  3. Click "+ Add Section" to create a numbering section. Each section can be set for a specific page range with a specific format (Roman numerals or regular numbers).
  4. Add more sections if your document needs more than one format — for example, the first section for the preface (Roman), the second for the body (regular numbers).
  5. Set the horizontal position (left, center, right) and vertical position (top, bottom) of the page numbers.
  6. Click apply, then download the resulting PDF.

Example setup for a thesis

The format commonly required by universities is usually: cover and title pages with no number at all, the preface through table of contents in small Roman numerals (i, ii, iii, and so on), then Chapter 1 onward in regular numbers starting again from 1. You can arrange exactly this by adding several sections matching each page range.

Which position is most commonly used?

"Bottom center" is the most common and neutral choice, suiting most formal documents. But check your institution's or publisher's writing guidelines first, since some specific formats require a particular position like top-right or bottom-right.

Frequently asked questions

Is my PDF uploaded to a server?

No. The entire numbering process runs directly in your browser.

Can I exclude certain pages from numbering?

Yes, by setting the page range for each section so that pages you don't want numbered (like the cover) aren't included in any section's range.

How many numbering sections can I add?

You can add as many as your document's structure needs.
