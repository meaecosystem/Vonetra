MEA Hub Is Now Synoltra

MEA Hub, the very first product that became the seed of MEA Ecosystem, has officially been renamed to Synoltra. Unlike some other products still in production, Synoltra is already fully live now on its new domain — this isn't just a surface-level name change.

October 21, 2026 · 1 min read
Product Status

Fully Live

Synoltra is already fully usable now on its new domain. Every feature that used to be in MEA Hub keeps working as normal — only the name and identity have changed.

Open Synoltra →

Why the name change?

In line with the rebranding of other products under MEA Ecosystem, the name "MEA Hub" was replaced so it could have a stronger identity of its own, moving away from the "MEA + function" pattern used before. The name Synoltra was chosen to reflect its role as the point where various services sync into one account.

New domain: synoltra.meaecosystem.com

Synoltra is now accessed through this domain:

synoltra.meaecosystem.com

The old domain will gradually be redirected to this new one.

What does Synoltra do?

Synoltra functions as an integration hub — connecting various external platforms into one account, so people don't have to keep switching apps to manage their work and productivity. Where Scholavi (formerly MEA Study) focuses on learning, Synoltra positions itself the other way around: focused on productivity.

Integrations already running right now include Notion and GitHub — including the ability to edit code directly from Synoltra. More platform integrations will keep being added going forward.

What doesn't change

The MEA Ecosystem name and logo as the parent brand stay exactly the same. Only this product's own name and identity are changing.

Summary

MEA Hub has officially been renamed to Synoltra and is now fully live at synoltra.meaecosystem.com. Its function stays the same: an integration hub connecting external platforms (Notion, GitHub, and more) into one account, with a new identity.
