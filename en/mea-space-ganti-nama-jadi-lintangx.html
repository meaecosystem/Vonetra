MEA Space Is Now LintangX

MEA Space, the product planned to be a hub for space exploration and sending messages to celestial objects, has officially been renamed to LintangX. The product is still in production, so it isn't accessible yet — but the name has already been locked in.

October 20, 2026 · 1 min read
Product Status

Coming Soon — Still in Production

LintangX's features aren't available to the public yet — the product is still being developed. The domain itself is already live and accessible, but for now it only shows a landing page. This page will be updated as there's further progress or a more definite release date.

Why the name change?

As part of the rebranding of products under MEA Ecosystem, the name "MEA Space" is being replaced with something more unique and with its own identity. The name initially considered was "Astravia," but after further checking, that name was already taken by another party, so it was changed to LintangX.

"Lintang" is Javanese/Indonesian for "star" — fitting for this product's role as a space for exploring the sky and outer space.

LintangX's domain

The LintangX domain is already live and can be visited at:

lintangx.meaecosystem.com

For now that page is just a landing page — there are no usable features yet, since the product itself is still in production.

What doesn't change

The MEA Ecosystem name and logo as the parent brand stay exactly the same as before. Only this product's own name and identity are changing.

Summary

MEA Space has officially been renamed to LintangX. The domain lintangx.meaecosystem.com is already live with a landing page, but the product's own features are still in production (coming soon).
