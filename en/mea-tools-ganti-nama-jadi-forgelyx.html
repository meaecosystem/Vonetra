MEA Tools Is Now Forgelyx

MEA Tools, the collection of everyday productivity tools built in-house — compressing, converting, and various other utilities — has officially been renamed to Forgelyx. It's already fully live now on its new domain, with every tool working just like before.

October 21, 2026 · 1 min read
Product Status

Fully Live

Forgelyx is already fully usable now on its new domain. Every tool that used to be in MEA Tools keeps working as normal — only the name and identity have changed.

Open Forgelyx →

Why the name change?

In line with the rebranding of other products under MEA Ecosystem, the name "MEA Tools" was replaced so it could have a stronger identity of its own, moving away from the "MEA + function" pattern used before. The name Forgelyx was chosen to evoke a "workshop" feel — the place where everyday productivity tools are forged and used.

New domain: forgelyx.meaecosystem.com

Forgelyx is now accessed through this domain:

forgelyx.meaecosystem.com

The old domain will gradually be redirected to this new one.

What doesn't change

Forgelyx's core principles stay exactly the same as when it was still called MEA Tools:

  • Free and watermark-free — no daily limits or hidden paywalls.
  • Processed right in your browser (client-side) — your files never need to be uploaded to a server to be processed.
  • Built from scratch — the PDF parser, image conversion, hashing, and other functions are all written in-house, not bolted on from third-party dependencies.

The MEA Ecosystem name and logo as the parent brand also stay the same — only this product's own name and identity are changing.

Summary

MEA Tools has officially been renamed to Forgelyx and is now fully live at forgelyx.meaecosystem.com. Every tool stays free, watermark-free, and processed right in your browser, just like before.
