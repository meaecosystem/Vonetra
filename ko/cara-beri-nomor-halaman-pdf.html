논문과 보고서용 PDF 페이지 번호 매기는 방법

논문과 보고서는 보통 서로 다른 페이지 번호 형식이 필요합니다: 서문은 로마 숫자, 본문은 일반 숫자, 표지는 번호 없음. 한 PDF 안에서 이를 설정하는 방법을 소개합니다.

2026년 10월 1일 · 읽는 시간 3분

PDF 페이지 번호 매기기는 한 문서 안에서 하나 이상의 번호 형식을 지원합니다 — 서로 다른 규칙을 가진 여러 "구간"을 만들 수 있어서, 표지는 번호 없음, 서문은 로마 숫자(i, ii, iii), 본문은 1부터 시작하는 일반 숫자로 설정할 수 있습니다. 학술 논문과 보고서에서 흔히 요구되는 표준 형식입니다.

페이지 번호 매기는 단계

  1. tools.meaecosystem.com/page-numbers를 엽니다.
  2. 번호를 매길 PDF 파일을 업로드합니다.
  3. "+ 구간 추가"를 클릭해 번호 구간을 만듭니다. 각 구간은 특정 페이지 범위에 특정 형식(로마 숫자 또는 일반 숫자)으로 설정할 수 있습니다.
  4. 문서에 여러 형식이 필요하면 구간을 더 추가하세요 — 예를 들어 첫 번째 구간은 서문(로마 숫자), 두 번째 구간은 본문(일반 숫자).
  5. 페이지 번호의 가로 위치(왼쪽, 가운데, 오른쪽)와 세로 위치(위, 아래)를 설정합니다.
  6. 적용을 클릭한 뒤 결과 PDF를 다운로드합니다.

논문용 설정 예시

학교에서 흔히 요구하는 형식은 보통: 표지와 제목 페이지는 번호 없음, 서문부터 목차까지는 작은 로마 숫자(i, ii, iii 등), 그리고 1장부터는 다시 1부터 시작하는 일반 숫자입니다. 각 범위에 맞춰 여러 구간을 추가해 정확히 이렇게 구성할 수 있습니다.

가장 흔히 쓰이는 위치는 어디인가요?

"가운데 아래"가 가장 흔하고 중립적인 위치로, 대부분의 공식 문서에 적합합니다. 다만 일부 특정 형식은 오른쪽 위나 오른쪽 아래 같은 특별한 위치를 요구하기도 하니, 소속 기관이나 출판사의 작성 지침을 먼저 확인하세요.

자주 묻는 질문

제 PDF가 서버로 업로드되나요?

아니요. 모든 번호 매기기 과정은 브라우저에서 직접 진행됩니다.

특정 페이지를 번호 매기기에서 제외할 수 있나요?

가능합니다. 각 구간의 페이지 범위를 설정해서 번호를 원하지 않는 페이지(예: 표지)가 어떤 구간에도 포함되지 않도록 하면 됩니다.

번호 구간을 몇 개까지 추가할 수 있나요?
