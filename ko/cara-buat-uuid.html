UUID(Universally Unique Identifier)는 다른 시스템과 조율할 필요 없이 무언가를 고유하게 식별하는 데 쓰이는 128비트 문자열입니다 — 두 개의 UUID v4가 무작위로 완전히 똑같을 확률은 거의 0에 가깝습니다. 이 툴은 가장 흔히 쓰이는 버전 4(난수 기반) UUID를 브라우저에서 바로 생성합니다.

UUID 만드는 단계

  1. tools.meaecosystem.com/uuid-generator를 엽니다.
  2. 한 번에 생성할 UUID 개수를 입력합니다.
  3. "UUID 생성"을 클릭합니다.
  4. 특정 UUID 하나를 옆의 버튼을 클릭해 복사하거나, 많이 필요하면 전체를 한꺼번에 복사합니다.

왜 순차적인 일반 숫자가 아니라 UUID를 써야 하나요?

순차적으로 증가하는 ID(1, 2, 3 등)는 추측하기 쉽고, 시스템이 지금까지 얼마나 많은 데이터를 생성했는지 같은 정보를 노출할 수 있습니다. UUID는 무작위적이고 순서가 없어서 URL이나 API 응답처럼 외부에 노출되는 곳에 사용하기 더 안전하며, ID 충돌 위험 없이 서로 다른 시스템의 데이터를 합치기도 쉽습니다.

자주 묻는 질문

여기서 만든 UUID가 서버로 전송되나요?

아니요. UUID는 난수를 사용해 브라우저에서 직접 생성되며, 어떤 데이터도 전송되지 않습니다.

다른 사람이 만든 UUID와 완전히 똑같을 수 있나요?

이론적으로는 가능하지만, 확률이 매우 작아서 실제로는 거의 일어나지 않는다고 간주됩니다.

UUID v4와 다른 버전의 차이는 무엇인가요?

UUID는 생성 방식에 따라 여러 버전이 있습니다. 버전 4는 순수하게 난수로 생성되며, 타임스탬프나 기기 주소 같은 추가 정보가 필요 없어 가장 단순하기 때문에 일상적인 용도로 가장 흔히 쓰입니다.
