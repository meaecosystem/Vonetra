정규식 테스트하는 단계

  1. tools.meaecosystem.com/regex-tester를 엽니다.
  2. 패턴 입력란에 정규식을 입력합니다.
  3. 필요한 플래그를 체크합니다: 첫 번째가 아닌 모든 일치 항목을 찾으려면 g, 대소문자 차이를 무시하려면 i, 여러 줄 모드는 m.
  4. 텍스트란에 테스트할 텍스트를 붙여넣거나 입력합니다.
  5. 패턴과 일치하는 부분이 바로 하이라이트되고, 전체 일치 개수가 표시됩니다.
  6. 패턴이 캡처 그룹용 괄호를 사용한다면, 각 일치 항목의 세부 정보(각 그룹의 내용 포함)가 아래에 나타납니다.

플래그 g, i, m — 언제 쓰나요?

g(전역) 플래그는 텍스트에서 처음 찾은 것뿐 아니라 패턴의 모든 출현을 찾고 싶을 때 필요합니다 — 보통 기본으로 활성화되어 있습니다. i 플래그는 대소문자 차이에 상관없이 — 예를 들어 대문자든 소문자든 신경 쓰지 않고 단어를 찾을 때 — 유용합니다. m 플래그는 ^와 $의 동작을 바꿔 전체 텍스트의 시작/끝이 아니라 각 줄의 시작/끝과 일치하도록 합니다 — 여러 줄로 된 텍스트에 유용합니다.

맞는 것 같은데 왜 패턴이 일치하지 않나요?

가장 흔한 원인: 특수 문자(마침표나 괄호처럼 정규식 문법이 아니라 일반 문자로 찾아야 하는 것)를 이스케이프하는 걸 깜빡했거나, 필요한 플래그를 체크하지 않은 경우입니다. 먼저 더 단순한 패턴으로 테스트 텍스트를 다시 하이라이트해보고, 문제가 되는 부분을 찾을 때까지 점진적으로 복잡도를 더해보세요.

자주 묻는 질문

제 패턴과 텍스트가 서버로 전송되나요?

아니요. 정규식 테스트는 JavaScript 내장 정규식 엔진을 사용해 브라우저에서 직접 진행됩니다.

모든 종류의 정규식이 지원되나요?

이 툴은 브라우저 내장 JavaScript 정규식 엔진을 사용하므로, 지원되는 문법은 JavaScript 정규식 표준을 따릅니다 — Python이나 PHP 같은 다른 프로그래밍 언어의 정규식과 비교하면 약간의 차이가 있을 수 있습니다.

캡처 그룹이 무엇인가요?

캡처 그룹은 괄호로 표시된 정규식 패턴의 일부로, 전체가 일치하는지 여부뿐 아니라 일치하는 텍스트의 특정 부분을 "포착"해서 추출하는 데 쓰입니다.
