민감한 문서를 이메일로 보내야 하는데 잘못된 사람에게 전달될까 걱정되시나요? 암호화 수준까지 직접 선택해서 PDF를 비밀번호로 잠그는 방법을 소개합니다.

PDF에 비밀번호 설정하는 단계

  1. tools.meaecosystem.com/protect-pdf를 엽니다.
  2. 보호할 PDF 파일을 업로드합니다.
  3. 새 비밀번호를 입력한 뒤 확인을 위해 다시 입력합니다.
  4. 암호화 수준을 선택합니다: AES-128 또는 AES-256.
  5. PDF 보호를 클릭한 뒤 결과를 다운로드합니다.

AES-128과 AES-256, 어느 것을 선택해야 하나요?

일반적인 용도에는 둘 다 충분히 안전합니다. AES-256은 더 긴 키를 사용하므로 이론적으로 더 강력하지만, AES-128은 AES-256을 지원하지 않을 수 있는 구버전 PDF 리더 소프트웨어와의 호환성이 더 좋습니다. 수신자의 소프트웨어를 확신할 수 없다면 AES-256이 안전한 기본 선택입니다.

본인이 설정한 비밀번호를 잊지 마세요

PDF가 비밀번호로 잠긴 뒤에는 올바른 비밀번호 없이는 다시 열 방법이 없습니다 — 그게 암호화의 목적입니다. 비밀번호 관리자 같은 안전한 곳에 저장해서 본인 문서에 대한 접근 권한을 잃지 않도록 하세요.

자주 묻는 질문

제 PDF와 비밀번호가 서버로 전송되나요?

아니요. 암호화 과정 전체가 브라우저에서 직접 진행되며, 파일과 비밀번호는 기기를 절대 떠나지 않습니다.

설정한 비밀번호를 잊어버리면 어떻게 되나요?

안타깝지만 올바른 비밀번호 없이 접근을 복구할 방법은 없습니다 — 강력한 암호화의 본질적인 특성입니다. 비밀번호를 안전한 곳에 보관하세요.

이미 잠긴 PDF를 여는 데도 쓸 수 있나요?

이 툴은 아직 잠기지 않은 PDF에 새 비밀번호를 추가하는 용도입니다. PDF에 이미 비밀번호가 있고 그것을(알고 있는 비밀번호로) 제거하고 싶다면 대신 Remove PDF Password 툴을 사용하세요.
