Unix 타임스탬프는 컴퓨터 시스템이 시간을 저장하는 방식입니다: 1970년 1월 1일 이후 경과한 초(또는 밀리초) 수입니다. 컴퓨터에게는 실용적이지만 사람이 바로 읽기는 어렵습니다. 이 툴은 양방향으로 변환합니다 — 타임스탬프에서 날짜로, 날짜에서 타임스탬프로.

왜 제 타임스탬프 숫자 길이가 다르게 보이나요?

단위의 문제입니다. 초 단위 타임스탬프는 보통 10자리(예: 1735689600)이고, 밀리초 단위 타임스탬프는 13자리(1735689600000)입니다 — 똑같은 값에 1000을 곱한 것뿐입니다. 변환 결과가 이상해 보인다면(예를 들어 연도가 수천 년 뒤로 나온다면) 단위를 잘못 선택했을 가능성이 큽니다. 이 툴은 둘 다 지원하니 단위를 다시 확인해보세요.

타임스탬프는 보통 어디에 쓰이나요?

서버 로그, 데이터베이스, API에서 가장 흔히 쓰입니다 — 숫자는 문자열 형태의 날짜 형식보다 비교하고 정렬하기가 훨씬 쉽기 때문입니다. 로그나 API 응답 데이터를 디버깅하고 있다면, 일반 날짜로 변환하는 것이 보통 데이터를 이해하기 쉽게 만드는 첫 단계입니다.

Unix Epoch란 무엇인가요?

Unix Epoch는 Unix 타임스탬프의 기준점인 1970년 1월 1일 00:00:00 UTC입니다. 모든 Unix 타임스탬프는 이 지점으로부터의 거리로 계산됩니다.
