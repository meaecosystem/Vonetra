하나의 PDF를 여러 파일로 나누는 방법

때로는 PDF 하나가 사실 여러 개의 다른 문서가 합쳐진 것일 때가 있습니다 — 책의 여러 장, 분리된 첨부 자료들, 또는 일부만 보내야 하는 페이지들이요. 필요에 맞게 별도 파일로 나누는 방법을 소개합니다.

2026년 8월 17일 · 읽는 시간 4분

합치기와 반대로, 때로는 큰 PDF 하나를 여러 개의 작은 파일로 나눠야 할 때가 있습니다 — 예를 들어 보고서의 3장만 보내야 하거나, 각 첨부 자료를 별도 파일로 분리해 보관하기 쉽게 만들고 싶을 때요.

PDF 분할하는 단계

  1. tools.meaecosystem.com/split-pdf를 엽니다 — 가입이나 로그인이 필요 없습니다.
  2. 기기에서 PDF 파일 하나를 선택하거나 업로드 영역으로 끌어다 놓습니다.
  3. 파일이 읽히면 모든 페이지가 순서대로 썸네일로 표시됩니다. 두 페이지 사이의 플러스 아이콘을 클릭해 그 지점에 분할 지점을 추가합니다.
  4. 더 빠른 방법을 원한다면 페이지 범위를 직접 입력하세요 — 예를 들어 1-3, 4-6, 7은 세 개의 파일로 나눕니다.
  5. "파일 분할" 버튼을 클릭합니다. 결과가 하나라면 바로 다운로드되고, 두 개 이상이면 자동으로 하나의 ZIP 파일로 묶입니다.

썸네일 클릭과 직접 범위 입력, 언제 어느 것을 쓰나요?

어느 페이지에서 정확히 나눠야 할지 아직 모를 때는 썸네일 사이를 직접 클릭하는 방식이 더 편합니다 — 각 페이지 내용을 먼저 확인하면서 분할 지점을 정할 수 있습니다. 반대로 분할 구조를 이미 정확히 알고 있다면(예: 문서 목차에 "1장: 1-12페이지, 2장: 13-25페이지"라고 나와 있다면) 범위를 직접 입력하는 게 하나씩 클릭할 필요가 없어서 훨씬 빠릅니다.

자주 묻는 질문

제 PDF 파일이 서버로 업로드되나요?

아니요. 분할 과정 전체가 브라우저에서 직접 진행됩니다 — 파일은 기기를 절대 떠나지 않습니다.

분할된 PDF의 품질이 떨어지나요?

아니요. 각 페이지의 원본 콘텐츠가 폰트와 이미지를 포함해 있는 그대로 복사되므로 원본 파일과 품질이 동일합니다.

분할 지점은 어떻게 정하나요?

두 페이지 사이의 플러스 아이콘을 클릭해 그 지점에 분할 지점을 추가하거나, 페이지 범위를 직접 입력하세요, 예: "1-3, 4-6, 7"로 세 개의 파일로 나눕니다.

왜 결과가 ZIP 파일로 다운로드되나요?

분할 결과가 두 개 이상이면, 한 번에 더 쉽게 다운로드할 수 있도록 자동으로 하나의 ZIP 파일로 묶입니다.
