HydraFusion: GitHub Copilot가 여러 AI 모델을 동시에 오케스트레이션하는 방법

GitHub가 이전까지 Copilot CLI에만 있던 기능인 HydraFusion을 VS Code와 Copilot 앱으로 확장했습니다. 새로운 AI 모델이 아니라, HydraFusion은 하나의 코딩 작업을 위해 여러 모델을 선택하고 조합하는 오케스트레이션 시스템입니다.

2026년 10월 30일 · 읽는 시간 4분

HydraFusion이란

Copilot의 모델 선택기에서 HydraFusion은 일반 모델 옵션처럼 보입니다. 하지만 그 이면에서는 추론, 코드 생성, 디버깅, 도구 사용 등 작업에 필요한 역량 신호를 평가한 뒤, 목표 품질에 도달하기 위한 가장 효율적인 워크플로를 결정합니다. 이 기능은 현재 리서치 프리뷰 단계이며, 처음에는 Copilot CLI에서만 제공되다가 2026년 9월 30일 VS Code와 GitHub Copilot 앱으로 확장되었습니다.

세 가지 워크플로 패턴

HydraFusion은 작업의 필요에 따라 다음 세 가지 패턴 중 하나를 실행합니다.

  • Single — 하나의 모델이 작업을 직접 처리합니다.
  • Cascade — 비용이 저렴한 모델이 먼저 초안을 작성하고, 품질 게이트가 그 초안이 충분한지, 더 강력한 모델로 올려야 하는지를 판단합니다.
  • Critique — 한 모델이 초안을 작성하고, 다른 계열의 모델이 읽기 전용으로 이를 검토합니다. 초안을 작성한 모델은 그 검토를 바탕으로 한 번 수정합니다.

벤치마크 결과

GitHub는 오프라인 평가를 통해 HydraFusion을 Claude Opus 5와 비교했습니다. TerminalBench 2.1에서는 품질이 4.9포인트 향상되었고 예상 비용은 67% 낮아졌습니다. DeepSWE에서는 상당한 비용 절감이 있었지만 정확한 수치는 공개되지 않았습니다.

이용 가능 여부

HydraFusion은 현재 VS Code(1.140 버전 이상 또는 VS Code Insiders)와 GitHub Copilot 앱에서 이용할 수 있으며, Pro, Pro+, Business, Enterprise 플랜 대상입니다. Business와 Enterprise의 경우 관리자가 조직 설정에서 프리뷰 기능을 먼저 활성화해야 합니다. 아직 리서치 프리뷰 단계이기 때문에 이 기능은 언제든 변경될 수 있습니다.

더 넓은 맥락

HydraFusion의 등장은 AI 코딩 에이전트 채택이 계속 늘어나는 큰 흐름과 맞닿아 있습니다. 2026년 9월 말 기준, 독립 리서치 기관 Amplifying.ai는 샘플링한 공개 풀 리퀘스트 중 약 32.5%가 AI 에이전트(Copilot, Claude Code, Cursor 등)에 의해 생성된 것으로 표시되었다고 기록했습니다 — 다만 일부 에이전트는 명시적인 PR 귀속으로 항상 확실하게 감지되지는 않기 때문에, 이 수치 일부는 추정치입니다.

자주 묻는 질문

HydraFusion은 새로운 AI 모델인가요?

아닙니다. HydraFusion은 기존 모델을 선택하고 조합하는 오케스트레이션 시스템이지, 처음부터 학습된 AI 모델이 아닙니다.

HydraFusion은 무료인가요?

HydraFusion은 Copilot Pro, Pro+, Business, Enterprise 구독자에게 제공되며, 무료 플랜에서는 이용할 수 없습니다. Business와 Enterprise의 경우 조직 관리자가 먼저 프리뷰 기능을 활성화해야 합니다.

HydraFusion은 Copilot의 Auto 모드와 어떻게 다른가요?

Auto는 요청마다 하나의 모델을 선택합니다. HydraFusion은 워크플로(single, cascade, critique)를 선택하며, 하나의 대화 턴 안에서 여러 모델을 조율할 수 있습니다.
