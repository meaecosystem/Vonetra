MEA Hub, Synoltra로 이름 변경

MEA Ecosystem의 출발점이 된 첫 번째 제품, MEA Hub가 공식적으로 Synoltra로 이름을 바꿨습니다. 아직 개발 중인 다른 제품들과 달리, Synoltra는 새 도메인에서 이미 완전히 서비스되고 있습니다 — 단순한 표면적 이름 변경이 아닙니다.

2026년 10월 21일 · 읽는 시간 2분
제품 상태

이미 완전히 서비스 중

Synoltra는 새 도메인에서 이미 완전히 이용 가능합니다. MEA Hub에 있던 모든 기능은 그대로 정상 작동하며, 바뀐 것은 이름과 정체성뿐입니다.

Synoltra 열기 →

왜 이름을 바꿨나?

MEA Ecosystem 산하 다른 제품들의 리브랜딩에 맞춰, "MEA Hub"라는 이름은 이전의 "MEA + 기능" 패턴에서 벗어나 더 독자적인 정체성을 갖도록 변경됐습니다. Synoltra라는 이름은 여러 서비스를 하나의 계정으로 동기화하는 지점이라는 역할을 반영합니다.

새 도메인: synoltra.meaecosystem.com

Synoltra는 이제 다음 도메인으로 접속할 수 있습니다.

synoltra.meaecosystem.com

기존 도메인은 단계적으로 이 새 도메인으로 리디렉션될 예정입니다.

Synoltra는 무슨 역할을 하나?

Synoltra는 통합 허브로서, 다양한 외부 플랫폼을 하나의 계정으로 연결해 업무와 생산성 관리를 위해 여러 앱을 오갈 필요가 없게 해줍니다. Scholavi(구 MEA Study)가 학습에 집중한다면, Synoltra는 그 반대로 생산성에 집중합니다.

현재 연동되어 있는 서비스는 Notion과 GitHub이며, Synoltra에서 직접 코드를 편집하는 것도 가능합니다. 앞으로 다른 플랫폼과의 연동도 계속 추가될 예정입니다.

변하지 않는 것

상위 브랜드인 MEA Ecosystem의 이름과 로고는 이전과 똑같이 유지됩니다. 변경되는 것은 이 제품 자체의 이름과 정체성뿐입니다.

요약

MEA Hub가 공식적으로 Synoltra로 이름을 바꿨으며, synoltra.meaecosystem.com에서 이미 완전히 서비스되고 있습니다. 역할은 그대로입니다 — Notion, GitHub 등 외부 플랫폼을 하나의 계정으로 통합하는 허브로, 새로운 정체성과 함께 운영됩니다.
