MEA Space, LintangX로 이름 변경

우주 탐사와 천체로의 메시지 전송을 계획했던 MEA Space가 공식적으로 LintangX로 이름을 바꿨습니다. 제품은 아직 개발 중이라 이용할 수는 없지만, 이름은 이미 확정됐습니다.

2026년 10월 20일 · 읽는 시간 2분
제품 상태

출시 예정 — 현재 개발 중

LintangX의 기능은 아직 대중에게 공개되지 않았습니다. 제품 자체가 개발 중입니다. 도메인은 이미 활성화되어 접속할 수 있지만, 현재는 랜딩 페이지만 보여줍니다. 추가 진행 상황이나 보다 확정적인 출시일이 나오면 이 페이지도 업데이트할 예정입니다.

왜 이름을 바꿨나?

MEA Ecosystem 산하 제품들의 리브랜딩 일환으로, "MEA Space"라는 이름은 더 독자적인 정체성을 가진 이름으로 교체됩니다. 처음 고려했던 이름은 "Astravia"였지만, 추가 확인 결과 이미 다른 곳에서 사용 중인 이름이라 LintangX로 변경했습니다.

"Lintang"은 자바어/인도네시아어로 "별"이라는 뜻으로, 하늘과 우주를 탐험하는 이 제품의 역할과 잘 어울립니다.

LintangX의 도메인

LintangX의 도메인은 이미 활성화되어 있으며, 아래 주소로 방문할 수 있습니다.

lintangx.meaecosystem.com

현재 해당 페이지는 랜딩 페이지일 뿐이며, 제품 자체가 아직 개발 중이라 사용할 수 있는 기능은 없습니다.

변하지 않는 것

상위 브랜드인 MEA Ecosystem의 이름과 로고는 이전과 똑같이 유지됩니다. 변경되는 것은 이 제품 자체의 이름과 정체성뿐입니다.

요약

MEA Space가 공식적으로 LintangX로 이름을 바꿨습니다. 도메인 lintangx.meaecosystem.com은 이미 활성화되어 랜딩 페이지를 보여주고 있지만, 제품 자체의 기능은 아직 개발 중(출시 예정)입니다.
